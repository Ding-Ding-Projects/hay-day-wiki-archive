# Design reference handoff

## Status

The Material Designer tool was unavailable in this session. No hosted design project is treated as a source of truth, and no design preview is treated as shipped reader behavior.

## Required follow-up

When the tool is available, create checked-in reference files under this directory and add one explicit inventory row per reference screen and state. Each row must name:

- reference file;
- deterministic reference route;
- matching built-reader route;
- state, theme, viewport, and display scale;
- Material Design 3 primitive audit;
- raw reference capture;
- raw built-reader capture;
- labelled side-by-side comparison;
- machine-readable visual diff;
- reviewed intentional deviations.

The capture tuple must match on both sides. The real built reader remains the source of implementation truth. The design tool is a viewing and handoff surface only.

## Current preview note

The initial reader preview establishes a farm-guide direction with warm cream surfaces, field greens, harvest accents, structured cards, responsive layout, and accessible typography. It remains a preview until the complete route and feature inventory is implemented and captured.
