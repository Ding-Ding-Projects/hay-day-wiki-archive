# Licensing and attribution

## Community-authored text

Community-authored text is generally reused under CC BY-SA 3.0 according to Fandom's licensing guidance. Each imported article must carry the original title, source permalink pinned to the imported revision, a history or contributor link, import timestamp, transformation and sanitization note, and a link to the applicable license.

The archive publishes adaptations under the applicable share-alike terms. It does not imply that every media file has the same license as the surrounding text.

## Media and third-party marks

Media rights are evaluated per file. Supercell-originated material is handled under [Supercell's Fan Content Policy](https://supercell.com/en/fan-content-policy/), not assumed to be CC BY-SA. The project is unofficial, non-commercial, and not endorsed by Supercell. It does not use Supercell imagery as a project logo, social-card decoration, or brand mark.

## Notice shown to readers

The reader must display a persistent notice: “This project is unofficial and is not endorsed by Supercell.” It must link to the Fan Content Policy and identify the source wiki. The notice is factual and does not claim partnership, sponsorship, or approval.

## Public boundaries

The project has no advertising, analytics, donations, payments, accounts, comments, public editing, or community moderation. Source attribution does not grant permission to copy a file whose per-file rights record is incomplete.
