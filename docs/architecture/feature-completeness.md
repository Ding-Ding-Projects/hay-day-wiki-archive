## Negative regression requirement

The completeness check must remove one exact inventory row, implementation link, documentation link, localization entry, persistence declaration, test record, built interaction record, and capture record at a time. Each removal must turn the check red, and restoration must turn it green. A discovery-only list is invalid because a missing feature would disappear from the list it is meant to protect.

## Surface limitation

This repository currently has a single public reader preview and no installed desktop runtime. The inventory therefore records browser-local equivalents for operating-system features, but does not claim those equivalents exist yet. The preview is not complete until every row has real implementation and built-output evidence.
