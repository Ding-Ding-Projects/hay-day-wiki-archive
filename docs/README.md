# Documentation

This documentation is grouped by the work a reader or maintainer needs to understand.

## Categories

- [Content](content/README.md): source scope, import, provenance, licensing, and attribution.
- [Media](media/README.md): rights decisions, digests, storage, and external video handling.
- [Architecture](architecture/README.md): schemas, routes, search, and completeness inventory.
- [Verification](verification/README.md): importer, security, reader, accessibility, and publication checks.

Every article states behavior, configuration, failure modes, security boundaries, and verification status. Unimplemented work is labelled explicitly.
