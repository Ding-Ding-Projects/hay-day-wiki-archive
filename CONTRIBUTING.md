# Contributing

Thank you for helping preserve a useful reader. Contributions should be small, reviewable, public-safe, and tied to a documented scope.

## Before editing

Read `AGENTS.md`, `ROADMAP.md`, the relevant feature article, and the current handoff. Check the current tree and keep unrelated changes intact.

## Content contributions

Content changes must identify the source page, source revision, source permalink, import time, and transformation. Do not add community conversations, user profiles, comments, or private-looking material to the reader scope without a written scope decision.

Do not copy media bytes unless the file's rights record supports reuse. Preserve a source-link-only record when rights are unclear. Never guess a license.

## Code and documentation

Every user-facing feature needs an implementation, documentation article, localized copy, persistence description where relevant, focused verification, built-output interaction proof, and real capture evidence. Add the feature to the hand-written completeness inventory in the same change.

Keep public files free of credentials, private session wording, machine-specific paths, and unverified claims. Use ordinary professional language in commits, issues, releases, and docs.

## Pull requests

Describe the exact behavior changed, source revision or manifest involved, verification commands, and remaining limitations. Include real built-output captures for visible changes. Mark planning, unrun, unavailable, and unverified states plainly.
